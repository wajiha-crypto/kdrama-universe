# K-Drama Universe
"What should I watch tonight?" - a Streamlit app on a PostgreSQL database of 3,550 Korean dramas
(IMDb data from Kaggle). 

Screens: Discover, Find similar, Taste Card, My list, Trends, Data stories,
Connections, Ask the data, Database overview.

Tech: PostgreSQL, Python, Streamlit, pandas, Altair.

Data: "The Ultimate Korean Drama Dataset 1969-2025" from Kaggle (built from IMDb).
The data file is not included here; download it from Kaggle.
